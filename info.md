# AlpicAir Climate Cards

Десять карточек для климата AlpicAir, включая стартовое меню с часами, погодой и настраиваемыми переходами к оборудованию.

- Визуальные редакторы для всех опций и кнопок управления
- Короткое нажатие и долгое удержание для кнопки настроек рекуператора
- Квадратные панели: кольцо, заголовок «Назад / Питание», меню закрываются по клику вне карточки
- Панель теплового насоса: индикаторы быстрых режимов (быстрый нагрев, тихий режим, дезинфекция)
- EN / RU / LV, светлая и тёмная темы
- Кольца используют совместимые с Home Assistant итоговые SVG-цвета без CSS-переменных в `stroke`
